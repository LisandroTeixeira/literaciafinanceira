# Origem dos conteúdos de poupança

O documento `poupanca-estudo.pdf` é a cópia integral do PDF de estudo enviado pelos autores em 9 de outubro de 2026: 45 páginas. Foi usado para redigir 33 novos conteúdos de poupança e aprofundar a interpretação de perguntas. Não substitui o PDF dos slides em `docs/pdf/apresentacao-poupanca.pdf`.

Em `docs/assets/knowledge.js`, os temas novos têm `sourcePages` com as páginas usadas como referência. As respostas são sínteses adaptadas ao chat, não uma reprodução integral do documento. Os exemplos e taxas são educativos e hipotéticos. As perguntas sobre bancos, preços e taxas atuais exigem consulta das condições atuais.

Foram consultadas também páginas educativas oficiais:
- https://www.todoscontam.pt/pt-pt/definir-objetivos
- https://www.todoscontam.pt/pt-pt/elaborar-o-orcamento
- https://www.todoscontam.pt/pt-pt/juro-simples-e-juro-composto

Este diretório está fora de `docs`: não é publicado pela configuração GitHub Pages indicada no README. O site não consulta o PDF para cada resposta; usa o conteúdo redigido e as regras locais incluídos no projeto.
